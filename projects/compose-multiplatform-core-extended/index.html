Overview개요

A fork of JetBrains' Compose Multiplatform core that adds libraries the ecosystem needs: a design system for Material 3 and multiplatform versions of Jetpack features that exist only on Android, such as OS notifications. They keep the androidx namespace.

JetBrains의 Compose Multiplatform 코어를 포크해서 생태계에 필요한 라이브러리를 더합니다. Material 3용 디자인 시스템, 그리고 OS 알림처럼 Android에만 있던 Jetpack 기능의 멀티플랫폼 버전입니다. androidx 네임스페이스를 그대로 씁니다.

The problem it solves푸는 문제

Platform features belong in Kotlin, where both Kotlin and Python apps can use them. Compose Multiplatform covers UI; many Jetpack features stay Android-only.

플랫폼 기능은 Kotlin 앱과 Python 앱이 모두 쓸 수 있는 Kotlin에 있어야 합니다. Compose Multiplatform은 UI를 다루지만, 많은 Jetpack 기능은 Android 전용으로 남아 있습니다.

How it works동작 방식

Each addition is an androidx-style multiplatform library with an implementation per platform: for notifications, NotificationCompat on Android, UNUserNotificationCenter on iOS and the system tray on desktop.

추가하는 것마다 플랫폼별 구현을 가진 androidx 방식의 멀티플랫폼 라이브러리입니다. 알림이라면 Android는 NotificationCompat, iOS는 UNUserNotificationCenter, 데스크톱은 시스템 트레이입니다.

Where it fits생태계 안의 위치

pythonx-platform's device features and pythonx-compose's Material 3 come from here, reached from Python through python-multiplatform's binder unchanged.

pythonx-platform의 기기 기능과 pythonx-compose의 Material 3가 여기서 나오고, Python은 python-multiplatform의 바인더로 그대로 닿습니다.

Where it stands현재 상태

In progress: design-system migration. Planned: OS notification API.

진행 중: 디자인 시스템 이전. 계획: OS 알림 API.

GitHub

What it is

A fork of JetBrains' Compose Multiplatform core that adds the libraries the ecosystem needs and Compose Multiplatform does not ship: a design system for Material 3, and multiplatform versions of Android-only Jetpack features such as OS notifications. They keep the androidx namespace, so a Kotlin app uses them like any Jetpack library and a Python app reaches them through the binder unchanged.

Why a fork

Features that belong to the platform should be written once, in Kotlin, where Kotlin and Python apps both get them. pythonx-platform's device features and pythonx-compose's Material 3 come from here.

무엇인가

JetBrains의 Compose Multiplatform 코어를 포크해서, 생태계에 필요하지만 Compose Multiplatform이 제공하지 않는 라이브러리를 더합니다. Material 3용 디자인 시스템, 그리고 OS 알림처럼 Android에만 있던 Jetpack 기능의 멀티플랫폼 버전입니다. androidx 네임스페이스를 그대로 써서 Kotlin 앱은 다른 Jetpack 라이브러리처럼 쓰고, Python 앱은 바인더로 그대로 닿습니다.

왜 포크인가

플랫폼에 속하는 기능은 Kotlin으로 한 번 쓰고 Kotlin 앱과 Python 앱이 함께 써야 합니다. pythonx-platform의 기기 기능과 pythonx-compose의 Material 3가 여기서 나옵니다.

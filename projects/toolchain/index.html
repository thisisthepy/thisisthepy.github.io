toolchain

A Gradle plugin that puts Python into a Kotlin Multiplatform app, and tcl, a one-verb installer for everyone else.Kotlin Multiplatform 앱에 Python을 넣는 Gradle 플러그인, 그리고 나머지 모두를 위한 한 단어 설치기 tcl.

GitHub · Guide · PyPI

What it is

toolchain is where a Kotlin build learns about Python. Its Gradle plugin adds a python { } block: name the Python version and the dependencies, and the plugin stages the interpreter, installs the dependencies per target through pypackpack, and packs everything into the desktop jar, the Android APK and the iOS app. Hot reload sends changed Python to a running app.

For people with no Gradle project, tcl (the toolchain-lite package on PyPI) does the install step with one verb: tcl install.

Where it is going

  • Published plugin, so any Kotlin Multiplatform app can apply it from a public repository.
  • CPython 3.15t by default, including the free-threaded interpreters we build for Android and iOS.
  • The web, isolated by default. For WebAssembly apps the plugin emits the cross-origin isolation headers threads need, for the dev server and for hosting, with a service-worker fallback for hosts that cannot set headers.

무엇인가

toolchain은 Kotlin 빌드가 Python을 알게 되는 곳입니다. Gradle 플러그인이 python { } 블록을 더합니다. Python 버전과 의존성을 적으면 플러그인이 인터프리터를 준비하고, pypackpack으로 타깃마다 의존성을 설치하고, 모두를 데스크톱 jar, Android APK, iOS 앱에 넣습니다. 핫 리로드는 바뀐 Python을 실행 중인 앱에 보냅니다.

Gradle 프로젝트가 없는 사람에게는 tcl(PyPI의 toolchain-lite 패키지)이 설치 단계를 한 단어로 합니다. tcl install.

어디로 가는가

  • 플러그인 공개 배포. 어떤 Kotlin Multiplatform 앱이든 공개 저장소에서 적용할 수 있게 합니다.
  • 기본 CPython 3.15t. 우리가 Android와 iOS용으로 빌드하는 free-threaded 인터프리터를 포함합니다.
  • 격리가 기본인 웹. WebAssembly 앱을 위해 스레드에 필요한 교차 출처 격리 헤더를 개발 서버와 호스팅용으로 생성하고, 헤더를 정할 수 없는 호스트에는 서비스 워커 대체를 넣습니다.

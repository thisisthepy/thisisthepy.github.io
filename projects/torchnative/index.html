Language and runtime

torchnative

PyTorch-style models on devices without PyTorch: a Rust runtime behind the API people already use.PyTorch가 없는 기기에서 PyTorch 방식의 모델을: 사람들이 이미 쓰는 API 뒤에 Rust 런타임을 둡니다.

GitHub · Guide

What it is

torchnative answers one question: how does a model that runs in a notebook run on a phone, unchanged? Its answer is to keep the API and replace what is underneath. Python code calls from_pretrained, generate and the familiar tensor operations; a runtime written in Rust executes them on CPU, Apple Metal, Vulkan and neural processing units, Intel NPUs included.

Real Hugging Face transformers models run from loading through generation, with streaming output and continuous batching, and their results are checked against upstream PyTorch on the CPU.

Why it matters for the ecosystem

An app built with python-multiplatform can already run Python on the device. torchnative gives it something worth running there: language models and other networks, without shipping a server, without the size of PyTorch, and without rewriting the model code. Gemstone, the ecosystem's chat application, is its first user.

Where it is going

  • 0.1.0b5: generation on Apple's Metal, the layout cleanup, and automated releases.
  • Built by pypackpack. The Python package and its Rust core become one pypackpack package, compiled for each target by pypackpack's Cargo backend.
  • Free-threaded wheels for CPython 3.15t, so inference runs beside a free-threaded app without turning the GIL back on.
  • 4-bit quantised weights, faster paged attention, and more model families.

무엇인가

torchnative는 한 가지 질문에 답합니다. 노트북에서 도는 모델을 고치지 않고 휴대폰에서 어떻게 돌리는가? 답은 API는 그대로 두고 그 아래를 바꾸는 것입니다. Python 코드는 from_pretrained, generate, 익숙한 텐서 연산을 부르고, Rust로 쓴 런타임이 그것을 CPU, Apple Metal, Vulkan, 그리고 Intel NPU를 포함한 신경망 처리 장치에서 실행합니다.

진짜 Hugging Face transformers 모델이 로딩부터 생성까지 돌고, 스트리밍 출력과 연속 배칭을 지원하며, 결과는 CPU에서 원래 PyTorch와 대조해 확인합니다.

생태계에서의 의미

python-multiplatform으로 만든 앱은 이미 기기에서 Python을 돌릴 수 있습니다. torchnative는 거기서 돌릴 가치가 있는 것을 줍니다. 서버도, PyTorch만큼의 용량도, 모델 코드 재작성도 없이 언어 모델과 다른 신경망을 돌립니다. 생태계의 채팅 앱 Gemstone이 첫 사용자입니다.

어디로 가는가

  • 0.1.0b5: Apple Metal에서의 생성, 저장소 구조 정리, 자동 배포.
  • pypackpack으로 빌드. Python 패키지와 Rust 코어가 하나의 pypackpack 패키지가 되고, pypackpack의 Cargo 백엔드가 타깃마다 컴파일합니다.
  • free-threaded 휠. CPython 3.15t용이라, free-threaded 앱 옆에서 GIL을 다시 켜지 않고 추론합니다.
  • 4비트 양자화 가중치, 더 빠른 paged attention, 더 많은 모델 계열.

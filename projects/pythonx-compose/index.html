GitHub · Guide · PyPI

What it is

pythonx-compose lets a Python programmer build real Jetpack and Compose Multiplatform interfaces without learning Kotlin first. Composables are Python functions with a decorator; the widgets are Compose's own Text, Button, Card, TextField, Column, Row; the screen is declared with @app; state is Compose's saved state through remember_saveable, read and written from anywhere, including a notebook cell.

It began as a lecture: "Python app development", a notebook in which a running app's screen is replaced and its state changed one cell at a time. That notebook is still the specification, and it runs end to end against an installed wheel.

Design

  • Declared, not updated. There is no update function. Redeclaring a root changes the screen.
  • A real package over real Compose. pythonx.compose imports androidx.compose through the binder and arranges it for Python; the Kotlin names stay what they are.
  • Text input stays in Compose. A TextField takes a Compose TextFieldState, so input-method composition (Korean, Japanese, Chinese) never round-trips through Python per keystroke.

Where it is going

  • Coroutine scopes for UI work on top of pythonx-concurrent.
  • Material 3 through the ecosystem's extended Compose core, with its design system.
  • 0.1.0b1: the whole lecture notebook usable from PyPI.

무엇인가

pythonx-compose는 Python 개발자가 Kotlin을 먼저 배우지 않고 진짜 Jetpack과 Compose Multiplatform 화면을 만들게 합니다. 컴포저블은 데코레이터가 붙은 Python 함수이고, 위젯은 Compose 자신의 Text, Button, Card, TextField, Column, Row입니다. 화면은 @app으로 선언하고, 상태는 remember_saveable로 얻는 Compose의 저장 상태라서 노트북 셀을 포함해 어디서든 읽고 씁니다.

시작은 강의였습니다. "Python 앱 개발 특강" 노트북에서 실행 중인 앱의 화면을 셀 하나씩 바꾸고 상태를 고칩니다. 그 노트북이 지금도 스펙이고, 설치된 wheel로 처음부터 끝까지 돕니다.

설계

  • 갱신하지 않고 선언한다. 업데이트 함수가 없습니다. 루트를 다시 선언하면 화면이 바뀝니다.
  • 진짜 Compose 위의 진짜 패키지. pythonx.compose는 바인더로 androidx.compose를 가져와 Python에 맞게 정리하고, Kotlin 이름은 그대로 둡니다.
  • 글자 입력은 Compose 안에서. TextField는 Compose의 TextFieldState를 받아서, 한글 같은 입력기 조합이 키를 누를 때마다 Python을 오가지 않습니다.

어디로 가는가

  • pythonx-concurrent 위의 UI 작업용 코루틴 스코프.
  • 생태계의 확장 Compose 코어를 통한 Material 3와 디자인 시스템.
  • 0.1.0b1: 강의 노트북 전체를 PyPI에서 설치해 쓸 수 있게.

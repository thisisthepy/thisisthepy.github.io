The idea

What plyer did for desktop Python, for apps on Kotlin Multiplatform: OS notifications, camera, sensors, file picking, sharing and permissions, with one Python API on Android, iOS and desktop.

The work is split the way the rest of the ecosystem is. The device features are implemented in Kotlin, as multiplatform androidx libraries in compose-multiplatform-core-extended, so Kotlin apps get them too. Python reaches them through the binder under their own names. pythonx-platform is the thin layer that makes them comfortable in Python, and it never reimplements a feature.

Status

Intent recorded and the name reserved on PyPI. The first Kotlin library, OS notifications, is planned in compose-multiplatform-core-extended.

아이디어

plyer가 데스크톱 Python에 해 준 일을 Kotlin Multiplatform 앱에 합니다. OS 알림, 카메라, 센서, 파일 선택, 공유, 권한을 Android, iOS, 데스크톱에서 하나의 Python API로 씁니다.

일은 생태계의 다른 부분과 같은 방식으로 나눕니다. 기기 기능은 Kotlin으로, compose-multiplatform-core-extended의 멀티플랫폼 androidx 라이브러리로 구현해서 Kotlin 앱도 함께 씁니다. Python은 바인더로 원래 이름 그대로 닿습니다. pythonx-platform은 그것을 Python에서 편하게 만드는 얇은 층이고, 기능을 다시 구현하지 않습니다.

상태

의도를 기록하고 PyPI 이름을 선점했습니다. 첫 Kotlin 라이브러리인 OS 알림은 compose-multiplatform-core-extended에 계획돼 있습니다.
